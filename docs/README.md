## 🧭 Dashboard Module Documentation

Detailed specifications for each dashboard pillar:

- **[market-price.md](./market-price.md)**: Multi-city live price checker, Black Market arbitrage tracker, historical candlestick charts, order spread analysis, and custom price alerts.
- **[crafting.md](./crafting.md)**: Station usage fee trackers, Resource Return Rate (RRR) analyzer (Base, Local, and Focus up to 53.9%), recipe explorer, focus cost curves, and labourers.
- **[farming.md](./farming.md)**: Island plot manager (3x3 grid), crop and herb growth timers, animal breeding and nutrition feeds, consumable pipelines, and daily net profit calculators.
- **[maps.md](./maps.md)**: Interactive world map (Royals, Outlands, Mists, Roads), zone tier & danger filters (Blue/Yellow/Red/Black), resource node density heatmaps, and Avalonian portal connections.
- **[guild.md](./guild.md)**: Member roster, roles & permissions, recruitment application review queue, announcements, Call To Arms (CTA) events & attendance tracking, and treasury auditing.
- **[calculation.md](./calculation.md)**: Precision calculators for crafting profit, step-by-step refining, fame & specialization progress (1-100/120), market taxes (Premium 4% vs Standard 8%), and inter-city transport arbitrage.
- **[others.md](./others.md)**: Community and player-demand features including the character build library, PvP killboard tracker, gathering yield logger, guides, player profile showcase, and feature voting.
